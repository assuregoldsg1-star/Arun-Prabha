Publish Your Website

Make your changes live with one tap. No downloads, no GitHub. Updates appear at assuregold.sg in about a minute.

⚡ One-Tap Publish

This sends all your current changes straight to your live website automatically. Your edits are already saved in the cloud, so you can publish from any device.

🔒 Secure - only you can publish, signed in with your code + email verification.
Advanced: download as ZIP instead (manual upload)

📥 Step 1 — Build Your Updated Website

Select your 3 current website files below. This tool will apply all your changes and give you a ZIP to download.

Pick index.html, collection.html and buyback.html together (hold Ctrl or Cmd to select all 3). Any photos you changed are included automatically.

📤 Step 2 — Push to GitHub

💻
Using GitHub Desktop (easiest)

Open GitHub Desktop → it detects the changed files automatically → type a short note like "update prices" → click Commit to main → click Push origin. Done.

🌐
Using github.com directly
  1. Unzip the downloaded file on your computer
  2. Open your website repo on github.com
  3. Click Add file → Upload files
  4. Drag in the updated files → click Commit changes
✅ Your website at assuregold.sg updates automatically in about 30 seconds.

💾 Backup (optional)

Save a backup file of all your content. Keep it somewhere safe — you can restore from it anytime.

📚 How To Use This Tool

💵 Change a Price

  1. Click Products & Prices in the menu
  2. Find the product, click Edit
  3. Change the price, click Save Product
  4. Go to Publish and follow the steps below

📷 Change a Photo

  1. Click Photos & Images
  2. Find the photo, click Replace
  3. Pick a new photo from your computer
  4. Publish as below

✏️ Edit Text or Carousel

  1. Click Website Text or Hero Carousel
  2. Edit the fields, click Save
  3. Publish as below

🚀 Publishing Your Changes

  1. Click Publish in the menu
  2. Select your 3 website files (index.html, collection.html, buyback.html)
  3. Click Build & Download ZIP — a ZIP downloads with all your changes
  4. Unzip it, then upload the files to your GitHub repository
  5. Your live website updates automatically in about 30 seconds

💾 Backups

In the Publish section you can Download Backup to save a copy of all your content. If anything goes wrong, use Restore Backup to load it back. Do this now and then to stay safe.
